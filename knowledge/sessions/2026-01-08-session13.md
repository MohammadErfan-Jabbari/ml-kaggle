## Key Findings

### 1. OOF is Systematically Overoptimistic

All methods show large OOF-Val gaps:
- Baseline: OOF 0.6666 → Val 0.6595 (+0.7%)
- PLS20: OOF 0.7431 → Val 0.6905 (+5.3%)
- Ensemble: OOF ~0.90 → Val 0.6967 (~+10%)

**Conclusion**: OOF cannot be trusted for model selection. Use Val only.

### 2. PLS20 is the Best Single Method

PLS(n=20) achieves +4.69% improvement over baseline on K.pneumoniae validation AUC.

### 3. Ensemble Adds Marginal Value

Ensemble (weighted by Val K.pn) achieves +5.64% over baseline, but only +0.91% over PLS20 alone.

**Question**: Is the added complexity worth +0.91%? Unknown until LB submission.

### 4. Val-LB Correlation Unknown

Previous best submission: OOF K.pn=0.7313 → LB=0.8328 (gap: ~12%)

Our ensemble: Val K.pn=0.6967 → LB=? (unknown)

**Cannot guarantee** this will beat LB 0.8328 without submission.

## Critical Insights

### On Model Selection

**Lesson**: OOF is unreliable for model selection in this competition.

**Why?**
- Training on 2688 samples (excluding val) vs full 3360
- CV sees different data distributions per fold
- Species distribution shift between train and test

**Solution**: Always use validation holdout for model selection.

### On Ensemble Methods

**Lesson**: Simple averaging provides value, but gains diminish quickly.

- PLS20 alone: +4.69%
- Ensemble (3 methods): +5.64%
- **Marginal gain**: +0.91% for 3x complexity

### On Kaggle Submissions

**Lesson**: Don't waste submissions without confidence.

- We have 3 submissions/day
- Val metrics don't directly translate to LB
- Need stronger signal before submitting

## Technical Notes

### val_predictions Implementation

Added to `ExperimentResult` dataclass:
```python

```

Modified `_aggregate_results()` to:
1. Accept `val_preds` parameter

This enables ensemble evaluation on validation set instead of OOF.

### Sanity Check Fix

Initial sanity check (ensemble must be between min and max of base models) was **wrong**.

Ensembles CAN be better than any single model - that's the point!

Fixed check:
```python
assert avg_kpn >= min_kpn, f"Averaging failed: {avg_kpn:.4f} < worst {min_kpn:.4f}"
if avg_kpn > max_kpn:
    print(f"★ Ensemble improves over best single: {avg_kpn:.4f} > {max_kpn:.4f}")
```
