## Key Achievements

### 1. Code Implementation
- Fixed `controlled_experiment.py` to handle Pipeline detection for supervised DR

### 2. Experiments Completed
- **14 methods tested** in ~12 minutes
- **3 methods beat baseline** (K.pn > 0.6946):
  1. LGB importance selection (500): K.pn = 0.7050 (+1.04%)
  2. PLS with n=7: K.pn = 0.7003 (+0.56%)
  3. VarianceThreshold (0.01): K.pn = 0.6973 (+0.27%)

### 3. Critical Finding
**None of the improvements are statistically significant** (p < 0.05):
- Best method (LGB FS): p = 0.55
- PLS(7): p = 0.74
- Variance: p = 0.61

This suggests the modest improvements could be due to random variation, not true method superiority.

## Key Insights

### Course Methods
- **PLS with n=7 validates course recommendation** - performs reasonably well
- **PLS with n=3 severely underfits** - n_components is critical
- **PLSCanonical underperforms PLSRegression** - symmetric deflation not helpful here
- **PCA→PLS pipeline adds no value** - complexity without benefit

### Modern DR
- **TruncatedSVD(200) best among SVD variants** - but still underperforms baseline
- **NMF mediocre** - despite MALDI literature support, doesn't beat baseline
- **More components generally better** for SVD (50 < 100 < 200)

### Feature Selection
- **LGB importance selection is the winner** - embedded method works best
- **VarianceThreshold preserves baseline performance** with fewer features (2674 → 5600)
- **Multi-stage pipeline underperforms** - complexity doesn't help

### Kernel Methods
- **KernelPCA (cosine) underperforms baseline** - non-linearity not needed
