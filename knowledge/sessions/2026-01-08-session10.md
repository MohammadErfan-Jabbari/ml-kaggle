## What Was Done

### 1. Plan Agent Consultation

Used Plan agent to evaluate implementation approach for per-species PLS. Key insight:
- `ControlledExperiment` only passes `(X, y)` to transformers, not species
- Solution: Augment X with species_id as feature 6001
- Plan agent recommended monkey-patching `_DATA_CACHE` to inject augmented data

### 2. PerSpeciesPLS Implementation

Added to `src/features/reducers.py`:
```python
class PerSpeciesPLS(BaseEstimator, TransformerMixin):
    """
    Train separate PLSRegression models per species.

    Extracts species from X[:, -1] during fit/transform.
    Fits PLS on fully-labeled samples per species.
    """
```

Key features:
- Skips species with <20 fully-labeled samples
- Stores `species_stats_` for debugging
- Returns zeros for species without trained models

### 3. AugmentedSpeciesExperiment Implementation

Created `experiments/run_phase3.py` with:
```python
class AugmentedSpeciesExperiment(ControlledExperiment):
    def run(self):
        # Load original data
        X, X_test, y, species, species_test = load_data()

        # Augment with species as last feature
        X_aug = np.hstack([X, species.reshape(-1, 1)])

        # Monkey-patch global cache
        original_cache = ce._DATA_CACHE
        ce._DATA_CACHE = (X_aug, X_test_aug, y, species, species_test)

        try:
            result = super().run()
        finally:
            ce._DATA_CACHE = original_cache
        return result
```

### 4. Bug Fixes During Implementation

## Design Insights

### Augment-X Approach

The "augment X" pattern (adding species_id as feature 6001) is a clean way to pass auxiliary information to transformers without modifying the experiment framework:

```python
# During fit: extract species from last column
species = X[:, -1].astype(int)
X_features = X[:, :-1]

# During transform: same extraction
species = X[:, -1].astype(int)
X_features = X[:, :-1]
```

This pattern could be reused for other scenarios requiring auxiliary info (e.g., fold ID, sample weights).
