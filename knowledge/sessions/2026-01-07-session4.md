## Key Finding

**The unified model approach is fundamentally flawed:**

The model's high OOF AUC (0.8978) is inflated by P. aeruginosa, which:
- Is 43% of training data
- Has trivial constant predictions (intrinsic resistance)
- Is only 3% of test data

K. pneumoniae, which is **51% of test**, gets only **0.7313 OOF AUC**.

Sample reweighting doesn't fix this because:
1. The model still sees the same features
2. P. aeruginosa patterns still dominate
3. Need fundamentally different approach

## Recommendation for Next Session

**Implement species-specific models:**
- Train separate LightGBM models for each species
- Route predictions by species_id at inference
- Expected improvement: K. pneumoniae AUC 0.73 → 0.80+, LB 0.83 → 0.85+
